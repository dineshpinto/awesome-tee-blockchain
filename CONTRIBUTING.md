# Contributing to Awesome TEE Blockchain

Please follow these guidelines to help keep everything clean, consistent, and up‑to‑date.

- **Formatting & Style:**
  - Alphabetize entries within each section/subsection.
  - Use the pattern: `- [Name](URL) – One‑sentence description.`.
  - Ensure headings use proper Markdown levels (##, ###).
  - Keep descriptions concise (max 80 characters).
- **Link Maintenance:**
  - Run link checks on new or updated URLs to avoid dead links.
  - Verify links open correctly and use HTTPS.
- **Table of Contents:**
  - After adding or removing headings, update the TOC. You can use [derlin/bitdowntoc](https://github.com/derlin/bitdowntoc) or similar.
- **Pull Request:**
  - Open a PR against `main` with a clear title in the form of `feat(new): project-name`.

Thank you for making this list better! 🎉
